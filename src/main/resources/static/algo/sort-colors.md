## 题意

数组 `nums` 里只有 0、1、2 三种值（分别代表红、白、蓝），要求**原地**把它排成所有 0 在前、1 在中、2 在后，不能用库函数排序。进阶：只扫一遍、常数空间。

```
输入：nums = [2,0,1,2,0,1]
输出：[0,0,1,1,2,2]
```

```
输入：nums = [2,2,0]
输出：[0,2,2]
```

## 思路

最朴素的是计数排序：先扫一遍数出 0、1、2 各几个，再扫一遍按个数回填。两遍扫描、O(1) 空间，已经能过，但进阶要求一遍完成。

一遍的做法是 Dijkstra 提出的**荷兰国旗问题**：用三个指针把数组划成四段。

```
[0, p0)      全是 0
[p0, i)      全是 1
[i, p2]      还没看过
(p2, n-1]    全是 2
```

`i` 从左往右扫描未知区，看 `nums[i]`：

- 是 0：和 `nums[p0]` 交换，`p0++`、`i++`。
- 是 1：本来就该在中间，`i++`。
- 是 2：和 `nums[p2]` 交换，`p2--`，**`i` 不动**。

直到 `i > p2`，未知区为空，排序完成。

:::tip 为什么对
正确性靠的是上面四段的**不变式**在每一步后都保持成立。遇到 0 时，换过来的 `nums[p0]` 属于 `[p0, i)` 段，一定是 1（或者 `p0 == i` 时就是自己），所以交换后 `i` 位置是 1，可以放心 `i++`。遇到 2 时，从 `p2` 换过来的是**未知区**里的数，还没检查过，所以 `i` 不能前进，要在下一轮重新判断。每一步要么 `i++` 要么 `p2--`，未知区严格缩小，最多 n 步结束；结束时未知区为空，四段只剩 0、1、2 三段，就是有序的。
:::

用 `nums = [2,0,1,2,0,1]` 推演：

```
nums            p0 i  p2  action
[2,0,1,2,0,1]   0  0  5   nums[i]=2, swap(i,p2), p2--
[1,0,1,2,0,2]   0  0  4   nums[i]=1, i++
[1,0,1,2,0,2]   0  1  4   nums[i]=0, swap(i,p0), p0++, i++
[0,1,1,2,0,2]   1  2  4   nums[i]=1, i++
[0,1,1,2,0,2]   1  3  4   nums[i]=2, swap(i,p2), p2--
[0,1,1,0,2,2]   1  3  3   nums[i]=0, swap(i,p0), p0++, i++
[0,0,1,1,2,2]   2  4  3   i > p2, stop
```

## Java 题解

```java
import java.util.*;

class Solution {
    public void sortColors(int[] nums) {
        // [0,p0) 为 0，[p0,i) 为 1，[i,p2] 未知，(p2,n-1] 为 2
        int p0 = 0, i = 0, p2 = nums.length - 1;
        while (i <= p2) {
            if (nums[i] == 0) {
                // 换过来的一定是 1（或自己），i 可以前进
                swap(nums, i, p0);
                p0++;
                i++;
            } else if (nums[i] == 2) {
                // 换过来的是未检查的数，i 不动
                swap(nums, i, p2);
                p2--;
            } else {
                i++;
            }
        }
    }

    private void swap(int[] nums, int a, int b) {
        int t = nums[a];
        nums[a] = nums[b];
        nums[b] = t;
    }
}
```

## 复杂度

- 时间 O(n)：每一步 `i++` 或 `p2--`，两者之间的未知区严格缩小，总步数不超过 n。
- 空间 O(1)：只有三个指针。

## 易错点

- 循环条件是 `i <= p2` 而不是 `i < n`：`p2` 右边已经是 2，再扫会把 2 换回来。也不能写成 `i < p2`，否则最后一个未知元素没检查。
- 遇到 2 交换后 `i` **不能**前进，这是最常见的错误，例如 `[1,2,0]`：交换后变成 `[1,0,2]`，如果 `i` 前进就会跳过换过来的 0，结果错误。
- 遇到 0 交换后 `i` **要**和 `p0` 一起前进；只动 `p0` 不动 `i` 会出现 `p0 > i`，打破不变式，例如 `[0,1]` 会把 0 又换到后面去。
- 计数排序写法虽然简单，但面试官如果明确要求一遍扫描，要能写出三指针版本。

## 其他解法

计数后回填，两遍扫描，最稳妥：

```java
import java.util.*;

class Solution {
    public void sortColors(int[] nums) {
        int[] cnt = new int[3];
        // 第一遍：统计 0、1、2 的个数
        for (int x : nums) cnt[x]++;
        // 第二遍：按个数依次回填
        int k = 0;
        for (int v = 0; v < 3; v++) {
            for (int c = 0; c < cnt[v]; c++) nums[k++] = v;
        }
    }
}
```

## 一句话记忆

三指针四段：0 往左换、i 前进；2 往右换、i 不动；1 直接跳过，直到 i 越过 p2。
