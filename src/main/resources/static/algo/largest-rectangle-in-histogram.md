## 题意

给一个非负整数数组 heights，表示宽度都为 1、紧挨着排列的柱子高度。在这些柱子围成的轮廓内能画出的最大矩形面积是多少？矩形必须底边贴地、由若干相邻的柱子支撑，高度取这些柱子里最矮的那个。

```
输入：heights = [3,1,4,5,2,4]
输出：8
解释：下标 2、3 的柱子高 4 和 5，取高度 4、宽度 2，面积 8；而下标 2~5 取高度 2、宽度 4，面积也是 8

输入：heights = [2,4,4]
输出：8
解释：下标 1、2 的两根 4 组成宽 2 高 4 的矩形
```

## 思路

暴力一：枚举左右端点，维护区间最小值，O(n²)。

暴力二：**枚举每根柱子作为矩形的高度**，从它向左、向右扩展，直到遇到比它矮的柱子为止，宽度 = 右边界 - 左边界 - 1。每根柱子扩展是 O(n)，总体仍是 O(n²)。

暴力二的瓶颈是「找左、右两侧第一个比它矮的柱子」，这正是单调栈擅长的事。维护一个**高度单调递增的栈**（存下标）：

- 当前柱子 i 比栈顶矮时，栈顶柱子的「右边第一个更矮」就是 i；
- 而栈顶柱子下面那个元素，就是它「左边第一个更矮」的柱子（栈是递增的）；
- 于是弹出栈顶 top，以 heights[top] 为高，宽度 = i - 新栈顶 - 1，结算面积。

为了让所有柱子最终都被结算，在数组两端各补一个高度为 0 的哨兵：左侧哨兵保证栈永不为空，右侧哨兵会把栈里剩余的柱子全部弹出。

:::tip 关键点
以每根柱子为高，找它左右第一个更矮的柱子。单调递增栈中，弹出时「当前元素」是右边界，「弹出后的新栈顶」是左边界。首尾补 0 哨兵省去所有边界判断。
:::

推演：补哨兵后 h = [0,3,1,4,5,2,4,0]，下标 0~7，栈中存下标：

```
i  h[i]  pop: height x width = area      stack after
1  3     -                               [0,1]
2  1     h=3 w=2-0-1=1 -> 3              [0,2]
3  4     -                               [0,2,3]
4  5     -                               [0,2,3,4]
5  2     h=5 w=5-3-1=1 -> 5              
         h=4 w=5-2-1=2 -> 8              [0,2,5]
6  4     -                               [0,2,5,6]
7  0     h=4 w=7-5-1=1 -> 4
         h=2 w=7-2-1=4 -> 8
         h=1 w=7-0-1=6 -> 6              [0,7]
max = 8
```

## Java 题解

```java
import java.util.*;

class Solution {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length;
        // 首尾各补一个高度 0 的哨兵
        int[] h = new int[n + 2];
        System.arraycopy(heights, 0, h, 1, n);
        // 单调递增栈，存下标
        Deque<Integer> stack = new ArrayDeque<>();
        int best = 0;
        for (int i = 0; i < n + 2; i++) {
            // 当前柱子比栈顶矮：栈顶柱子的右边界找到了
            while (!stack.isEmpty() && h[i] < h[stack.peek()]) {
                int height = h[stack.pop()];
                // 弹出后的新栈顶就是左边第一个更矮的柱子
                int width = i - stack.peek() - 1;
                best = Math.max(best, height * width);
            }
            stack.push(i);
        }
        return best;
    }
}
```

## 复杂度

- 时间 O(n)：每个下标入栈、出栈各一次。
- 空间 O(n)：栈和补了哨兵的数组。

## 易错点

- 栈中存下标，宽度用 `i - 新栈顶 - 1` 计算，而不是 `i - 弹出的下标`：弹出的柱子左边可能还有更高的柱子已经被弹掉了，它们也在矩形范围内。
- 不加哨兵时，要单独处理「栈空时左边界为 -1」和「遍历结束后栈里还有柱子」两种情况，很容易漏。
- 比较用 `<`：相等高度的柱子留在栈里，最后由右边更矮的柱子一起以完整宽度结算。如果改成 `<=`，末尾哨兵 0 会把左侧哨兵 0 也弹掉，`stack.peek()` 取到 null 报错。
- `height * width` 最大约 10^4 × 10^5 = 10^9，在 int 范围内；如果数据范围更大要用 long。
