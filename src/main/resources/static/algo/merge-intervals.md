## 题意

给一组闭区间 `intervals[i] = [start, end]`，把所有有重叠的区间合并起来，返回合并后互不重叠、且覆盖了原来所有区间的区间数组。端点相接（如 `[1,3]` 和 `[3,5]`）也算重叠。输入不保证有序。

```
输入：intervals = [[8,10],[1,4],[3,6],[12,15],[10,11]]
输出：[[1,6],[8,11],[12,15]]
```

```
输入：intervals = [[2,9],[3,4]]
输出：[[2,9]]
解释：[3,4] 被 [2,9] 完全包含
```

## 思路

暴力：反复找任意两个能合并的区间合并，直到没有可以合并的为止，最坏 O(n²) 甚至更多。

关键是**按起点排序**。排序后，能和当前区间合并的区间一定紧挨在它后面，而且只需要和"结果列表里最后一个区间"比较：

- 如果新区间的起点 `<=` 最后一个区间的终点，说明重叠，把最后一个区间的终点更新为两者终点的较大值；
- 否则不重叠，新区间直接加入结果。

:::tip 关键点
排序后，重叠只可能发生在相邻区间之间；合并时终点要取 `max`，因为可能出现"大区间包住小区间"的情况。
:::

排序后 `[[1,4],[3,6],[8,10],[10,11],[12,15]]`：

```
cur      last in res   overlap?   res
[1,4]    -             -          [1,4]
[3,6]    [1,4]         3<=4 yes   [1,6]
[8,10]   [1,6]         8<=6 no    [1,6] [8,10]
[10,11]  [8,10]        10<=10 yes [1,6] [8,11]
[12,15]  [8,11]        12<=11 no  [1,6] [8,11] [12,15]
```

## Java 题解

```java
import java.util.*;

class Solution {
    public int[][] merge(int[][] intervals) {
        // 按起点升序排序
        Arrays.sort(intervals, (a, b) -> Integer.compare(a[0], b[0]));
        List<int[]> res = new ArrayList<>();
        for (int[] cur : intervals) {
            int[] last = res.isEmpty() ? null : res.get(res.size() - 1);
            if (last == null || cur[0] > last[1]) {
                // 不重叠：新开一个区间（拷贝一份，避免修改输入）
                res.add(new int[]{cur[0], cur[1]});
            } else {
                // 重叠：扩展终点，注意取较大值（可能被包含）
                last[1] = Math.max(last[1], cur[1]);
            }
        }
        return res.toArray(new int[0][]);
    }
}
```

## 复杂度

- 时间 O(n log n)：排序占主导，合并只扫一遍。
- 空间 O(log n)：排序的栈空间（不计结果）。

## 易错点

- 合并时写成 `last[1] = cur[1]` 会在包含关系下出错，如 `[[2,9],[3,4]]` 会变成 `[2,4]`。
- 端点相接也要合并，判断条件是 `cur[0] > last[1]` 才算不重叠，别写成 `>=`。
- 比较器用 `Integer.compare`，`a[0] - b[0]` 在极端值时可能溢出。
- `List<int[]>` 转二维数组用 `toArray(new int[0][])`。

## 一句话记忆

按起点排序，和结果里最后一个区间比：重叠就把终点取大，不重叠就新开。
