## 题意

实现一个把字符串转成 32 位有符号整数的函数（类似 C 的 `atoi`），规则依次是：跳过开头的空格；读一个可选的 `+` 或 `-`；然后尽可能多地读连续数字，遇到第一个非数字字符就停；没读到任何数字返回 0；结果超出 `[-2³¹, 2³¹-1]` 时截断到边界值。

```
输入：s = "   -0042abc"
输出：-42
解释：跳过空格，读到负号，读 0042，遇到 a 停止
```

```
输入：s = "91283472332"
输出：2147483647
解释：超过 int 最大值，截断
```

```
输入：s = "words 12"
输出：0
解释：第一个非空字符不是数字也不是符号
```

## 思路

这题没有算法难点，考的是**把规则拆成清晰的阶段**和**不借助 long 的溢出判断**。按顺序处理：空格 → 符号 → 数字，一个指针从左走到右即可。

溢出判断是核心：每读一位 `d` 就要做 `res = res * 10 + d`，在做之前先检查这一步会不会超过 `Integer.MAX_VALUE`：`res > MAX / 10`，或者 `res == MAX / 10` 且 `d > 7`（MAX = 2147483647，末位是 7）。一旦会溢出，直接按符号返回 MAX 或 MIN。

为什么负数也能用 `d > 7` 判断？负数边界是 -2147483648，绝对值末位是 8。当 `res == 214748364` 且 `d == 8` 时按规则应该返回 MIN，而截断返回的恰好也是 MIN，所以统一写成 `d > 7` 就截断，结果依然正确。

:::tip 关键点
先检查再累加：`res > MAX/10 || (res == MAX/10 && d > 7)` 就按符号返回边界值。整个过程用正数累加，最后乘上符号。
:::

用 `"   -0042abc"` 推演：

```
i  字符  阶段    res  sign
0  ' '   跳空格  0    1
3  '-'   符号    0    -1
4  '0'   数字    0
5  '0'   数字    0
6  '4'   数字    4
7  '2'   数字    42
8  'a'   停止 -> -42
```

## Java 题解

```java
import java.util.*;

class Solution {
    public int myAtoi(String s) {
        int n = s.length(), i = 0;
        // 1. 跳过前导空格
        while (i < n && s.charAt(i) == ' ') i++;
        // 2. 可选符号
        int sign = 1;
        if (i < n && (s.charAt(i) == '+' || s.charAt(i) == '-')) {
            sign = s.charAt(i) == '-' ? -1 : 1;
            i++;
        }
        // 3. 连续数字，累加前先判断溢出
        int res = 0;
        while (i < n && s.charAt(i) >= '0' && s.charAt(i) <= '9') {
            int d = s.charAt(i) - '0';
            if (res > Integer.MAX_VALUE / 10 || (res == Integer.MAX_VALUE / 10 && d > 7)) {
                return sign == 1 ? Integer.MAX_VALUE : Integer.MIN_VALUE;
            }
            res = res * 10 + d;
            i++;
        }
        return sign * res;
    }
}
```

## 复杂度

- 时间 O(n)：指针只从左到右走一遍。
- 空间 O(1)：只用了几个变量。

## 易错点

- 符号只能出现一次，且必须紧跟在空格之后：`"+-12"` 读到 `+` 后下一个是 `-` 不是数字，结果为 0。
- 空格之后、符号之前不能有别的字符；数字中间出现空格也要停止，`"12 34"` 结果是 12。
- 用 `res * 10 + d` 之后再判断是否溢出已经晚了，int 会先回绕成负数；要么先判断，要么用 long 并在每一步截断。
- 用 long 累加时也不能等读完再比较，`"99999999999999999999"` 会让 long 本身溢出，必须每一步都检查。
- `Character.isDigit` 会把全角数字、阿拉伯文数字等 Unicode 数字也当成数字，这里只应接受 `'0'..'9'`。
- 只跳过空格 `' '`，题目并没有要求跳过制表符等其他空白字符。
