## 题意

给一个只由 `()[]{}` 六种字符组成的字符串，判断括号是否合法：每个左括号都必须被**同类型**的右括号闭合，并且闭合顺序正确（后打开的先关闭）。

```
输入：s = "{[()]}()"
输出：true

输入：s = "([)]"
输出：false
解释：[ 还没关闭，就先出现了 )，与最近未闭合的 [ 不匹配
```

## 思路

暴力做法：反复把字符串里相邻的 `()`、`[]`、`{}` 删掉，直到删不动，最后看是否为空。每轮 O(n)，最多 n/2 轮，O(n²)。

观察这个过程：真正决定能否匹配的是「**最近一个还没闭合的左括号**」。最近打开的最先关闭，正是后进先出，用栈：

- 遇到左括号，入栈；
- 遇到右括号，栈顶必须是与之配对的左括号，是则弹出，否则失败（栈空也失败）；
- 扫描结束后栈必须为空，否则有左括号没关闭。

:::tip 关键点
括号匹配 = 栈。一个小技巧：遇到左括号时直接把**它期望的右括号**压栈，之后遇到右括号只需判断是否等于栈顶，代码更短。
:::

推演 `"{[()]}()"`（栈里存期望的右括号）：

```
char  stack     动作
{     }         压入 }
[     } ]       压入 ]
(     } ] )     压入 )
)     } ]       匹配弹出
]     }         匹配弹出
}     (empty)   匹配弹出
(     )         压入 )
)     (empty)   匹配弹出，最终为 true
```

## Java 题解

```java
import java.util.*;

class Solution {
    public boolean isValid(String s) {
        // 奇数长度不可能完全配对
        if (s.length() % 2 == 1) return false;
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            // 左括号：压入它期望的右括号
            if (c == '(') stack.push(')');
            else if (c == '[') stack.push(']');
            else if (c == '{') stack.push('}');
            // 右括号：必须和栈顶期望的一致
            else if (stack.isEmpty() || stack.pop() != c) return false;
        }
        // 还有没闭合的左括号则不合法
        return stack.isEmpty();
    }
}
```

## 复杂度

- 时间 O(n)：每个字符入栈出栈至多一次。
- 空间 O(n)：最坏全是左括号，全部入栈。

## 易错点

- 遇到右括号时先判断栈是否为空，否则 `")"` 这种输入会抛异常。
- 扫描结束后要检查栈为空，`"(("` 这种只开不关的情况在循环里发现不了。
- `stack.pop() != c` 比较的是 `Character` 拆箱后的 char，没问题；但如果两边都是 `Character` 对象，用 `!=` 会比较引用，是个隐患。
- 只有一种括号时可以用计数器代替栈，但多种括号必须用栈，计数器判断不了 `"([)]"`。
