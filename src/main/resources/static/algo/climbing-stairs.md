## 题意

楼梯一共 `n` 级，每一步可以跨 1 级或 2 级，问从地面走到第 `n` 级一共有多少种不同的走法。`n` 是正整数（最大 45，结果不会超出 int）。

```
输入：n = 4
输出：5
解释：1+1+1+1、1+1+2、1+2+1、2+1+1、2+2，共 5 种
```

```
输入：n = 1
输出：1
```

## 思路

暴力做法是递归枚举：站在第 `i` 级，下一步要么 +1 要么 +2，每一层分叉两次，时间 O(2^n)。瓶颈在于大量重复子问题：算 `f(5)` 要算 `f(4)` 和 `f(3)`，算 `f(4)` 又要再算一遍 `f(3)`。

换个角度倒着想：要到达第 `i` 级，**最后一步**只有两种可能——从 `i-1` 跨 1 级上来，或从 `i-2` 跨 2 级上来。这两类走法互不重叠，所以方案数直接相加。

- **dp 定义**：`dp[i]` = 从地面走到第 `i` 级的走法数。
- **转移**：`dp[i] = dp[i-1] + dp[i-2]`。
- **初始化**：`dp[0] = 1`（站在地面不动，算一种"空走法"），`dp[1] = 1`。
- **遍历顺序**：`i` 从 2 递增到 `n`，因为 `dp[i]` 依赖左边两个值。

:::tip 关键点
按"最后一步"分类是 DP 最常用的拆分方式：分类要**不重不漏**，方案数才能相加。本题转移式就是斐波那契数列。
:::

用 `n = 4` 填表：

```
i       0  1  2  3  4
dp[i]   1  1  2  3  5
                 ^ dp[3] = dp[2] + dp[1] = 2 + 1
```

**滚动数组优化**：`dp[i]` 只依赖前两项，用两个变量 `prev2, prev1` 滚动即可，空间从 O(n) 降到 O(1)。

## Java 题解

```java
import java.util.*;

class Solution {
    public int climbStairs(int n) {
        // prev2 = dp[i-2], prev1 = dp[i-1]，初始对应 dp[0] = 1, dp[1] = 1
        int prev2 = 1, prev1 = 1;
        for (int i = 2; i <= n; i++) {
            // 最后一步跨 1 级 或 跨 2 级
            int cur = prev1 + prev2;
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }
}
```

## 复杂度

- 时间 O(n)：从 2 到 n 各算一次，每次 O(1)。
- 空间 O(1)：滚动数组只保留前两项；如果开完整 `dp` 数组则是 O(n)。

## 易错点

- `dp[0]` 取 1 而不是 0：它表示"已经到达"的那一种方式，取 0 会让 `dp[2]` 算成 1。
- `n = 1` 时循环一次都不执行，要直接返回 `prev1 = 1`，不要写成返回 `prev2` 或 `cur`。
- 滚动更新的顺序：先算 `cur`，再 `prev2 = prev1`，最后 `prev1 = cur`，顺序反了就会丢值。
- 纯递归不加记忆化会超时；加 `memo` 数组后也是 O(n)，面试时可以先说递归再改成迭代。

## 其他解法

记忆化递归：自顶向下写法，和递推本质相同，更贴近"最后一步"的推导过程。

```java
import java.util.*;

class Solution {
    private int[] memo;

    public int climbStairs(int n) {
        memo = new int[n + 1];
        return f(n);
    }

    private int f(int i) {
        if (i <= 1) return 1;          // 地面和第 1 级都只有一种
        if (memo[i] != 0) return memo[i];
        return memo[i] = f(i - 1) + f(i - 2);
    }
}
```

- [[algo:coin-change]]：每步可走的"步长"从 {1,2} 变成任意硬币面额，求最少步数而不是方案数。
- [[algo:unique-paths]]：一维的"从上一步来"扩展到二维"从上方或左方来"。
