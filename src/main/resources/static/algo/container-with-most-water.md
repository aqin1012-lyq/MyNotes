## 题意

数组 `height` 的第 i 个元素表示在横坐标 i 处立着一根高为 `height[i]` 的竖线。任选两根竖线，和 x 轴一起围成一个容器，能装的水量 = 两线间距 × 较矮那根的高度。求最大水量。

```
输入：height = [2,5,4,1,6,3]
输出：15
解释：选下标 1 (高 5) 和下标 4 (高 6)，宽 3，高 min(5,6)=5，面积 15
```

```
输入：height = [3,3]
输出：3
```

## 思路

暴力：枚举所有 (i, j)，算 `(j - i) * min(h[i], h[j])` 取最大，O(n²)。

优化的关键是想清楚"哪些组合根本不用试"。左右指针从两端开始，此时宽度最大。设 `h[l] < h[r]`：

- 以 `l` 为左边、和 `r` 左侧任何一根 `k` 配对，宽度更小，高度也不会超过 `h[l]`，面积一定不超过当前面积。
- 所以 `l` 作为左端点的所有可能已经"被当前这次计算代表了"，可以放心 `l++` 丢弃它。

每次移动**较矮**的一边，n 步就能结束。

:::tip 关键点
面积受短板限制。移动高的一边宽度变小、短板不变甚至更矮，只会更差；只有移动矮的一边才**可能**遇到更高的板子。每次移动都安全地排除了一整行/一整列候选。
:::

推演 `[2,5,4,1,6,3]`：

```
l  r  h[l] h[r]  area            move
0  5  2    3     5*2 = 10        l++
1  5  5    3     4*3 = 12        r--
1  4  5    6     3*5 = 15        l++
2  4  4    6     2*4 = 8         l++
3  4  1    6     1*1 = 1         l++
l == r, stop, best = 15
```

## Java 题解

```java
import java.util.*;

class Solution {
    public int maxArea(int[] height) {
        int l = 0, r = height.length - 1;
        int best = 0;
        while (l < r) {
            // 面积 = 宽 × 短板
            int h = Math.min(height[l], height[r]);
            best = Math.max(best, (r - l) * h);
            // 移动较矮的一边：矮的那根和任何更近的线配对都不可能更大
            if (height[l] < height[r]) l++;
            else r--;
        }
        return best;
    }
}
```

## 复杂度

- 时间 O(n)：每轮 l 或 r 移动一步，总共最多 n-1 轮。
- 空间 O(1)。

## 易错点

- 移动的是**较矮**的一边，写反了就会漏掉最优解。
- 两边相等时移动任意一边都可以：两根一样高时，任何一根和中间的线配对都不会超过当前面积。
- 面积是 `(r - l) * min`，宽度不要写成 `r - l + 1`，线是没有宽度的。
- 和"接雨水"区分开：这里只看两根线，中间的线不挡水。
