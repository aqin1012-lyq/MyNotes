## 题意

给一个整数数组 `nums`，返回数组 `answer`，其中 `answer[i]` 等于除了 `nums[i]` 之外所有元素的乘积。**不能用除法**，要求 O(n) 时间。题目保证任何前缀/后缀乘积都在 int 范围内。

```
输入：nums = [2,3,4,5]
输出：[60,40,30,24]
解释：answer[0] = 3*4*5 = 60，answer[1] = 2*4*5 = 40 ……
```

```
输入：nums = [3,0,2,-1]
输出：[0,-6,0,0]
解释：只有去掉 0 的那个位置结果非零：3*2*(-1) = -6
```

## 思路

暴力：对每个 i 把其余元素乘一遍，O(n²)。

用除法：先求总乘积再除以 `nums[i]`，但题目禁止，而且遇到 0 要特殊处理。

换个拆法：`answer[i] = (i 左边所有数的乘积) × (i 右边所有数的乘积)`。

- 从左往右扫一遍，得到每个位置的前缀积 `left[i]`（不含 i）；
- 从右往左扫一遍，得到后缀积 `right[i]`（不含 i）；
- 两者相乘即可。

进一步省空间：直接把前缀积写进 `answer`，第二遍从右往左时用一个变量 `suffix` 累乘，边走边乘到 `answer[i]` 上，除了输出数组外只用 O(1) 空间。

:::tip 关键点
"除自己以外" = 左边的积 × 右边的积。两次方向相反的扫描，天然就不会把自己乘进去，也就不怕 0。
:::

推演 `[2,3,4,5]`：

```
i                0    1    2    3
nums             2    3    4    5
prefix (excl.)   1    2    6    24
suffix (excl.)   60   20   5    1
answer           60   40   30   24
```

## Java 题解

```java
import java.util.*;

class Solution {
    public int[] productExceptSelf(int[] nums) {
        int n = nums.length;
        int[] ans = new int[n];
        // 第一遍：ans[i] = nums[0..i-1] 的乘积（左侧前缀积）
        ans[0] = 1;
        for (int i = 1; i < n; i++) {
            ans[i] = ans[i - 1] * nums[i - 1];
        }
        // 第二遍：从右往左，suffix = nums[i+1..n-1] 的乘积
        int suffix = 1;
        for (int i = n - 1; i >= 0; i--) {
            ans[i] *= suffix;
            suffix *= nums[i]; // 乘完再把自己并入后缀
        }
        return ans;
    }
}
```

## 复杂度

- 时间 O(n)：两次遍历。
- 空间 O(1)：输出数组不计入额外空间，只用了一个变量 `suffix`。

## 易错点

- 前缀积要"不含自己"：`ans[i] = ans[i-1] * nums[i-1]`，下标错一位就会把自己乘进去。
- 第二遍里先 `ans[i] *= suffix` 再 `suffix *= nums[i]`，顺序反了同样会把自己乘进去。
- 不要试图用"总乘积 / nums[i]"——题目禁止，而且有 0 时会除零。
- `ans[0]` 初始化为 1（空前缀的乘积是 1，不是 0）。
