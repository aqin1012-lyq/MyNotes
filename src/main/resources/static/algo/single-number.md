## 题意

给一个非空整数数组，其中只有一个元素出现了**一次**，其余每个元素都**恰好出现两次**，找出那个只出现一次的元素。要求线性时间，并且只用常数额外空间。

```
输入：nums = [7,3,5,3,7]
输出：5
```

```
输入：nums = [-4,9,9]
输出：-4
解释：负数同样适用
```

## 思路

常规做法有两种：用 HashSet，见到一个数就加入、再见到就移除，最后剩下的就是答案，O(n) 时间但 O(n) 空间；或者先排序再两两比较，O(n log n)。题目要求 O(1) 空间，这两种都不满足。

突破口是**异或（XOR）**的三条性质：

- `a ^ a = 0`：相同的数异或抵消。
- `a ^ 0 = a`：和 0 异或不变。
- 满足**交换律和结合律**：一串数异或的结果与顺序无关。

所以把所有数异或起来，可以在脑中把它重新排成 `(a^a) ^ (b^b) ^ ... ^ x`，每一对都变成 0，最后只剩 `x`。

:::tip 为什么对
换成按位看更直观：异或的每一位就是"这一位上 1 的个数的奇偶性"。出现两次的数在每一位上贡献的 1 都是偶数个，不影响奇偶；只有出现一次的数会让它为 1 的那些位变成奇数。所以最终每一位的奇偶正好等于答案的那一位。负数在 Java 里是补码，同样逐位成立，不需要特殊处理。
:::

用 `nums = [7,3,5,3,7]` 推演（二进制取低 3 位）：

```
step  num  bin   acc(bin)  acc
init   -    -    000       0
1      7    111  111       7
2      3    011  100       4
3      5    101  001       1
4      3    011  010       2
5      7    111  101       5
```

中间值看起来很乱，但因为顺序不影响结果，最终一定等于 `7^7^3^3^5 = 5`。

## Java 题解

```java
import java.util.*;

class Solution {
    public int singleNumber(int[] nums) {
        int acc = 0; // 0 是异或的单位元
        for (int x : nums) {
            // 成对出现的数会互相抵消，只剩下出现一次的那个
            acc ^= x;
        }
        return acc;
    }
}
```

## 复杂度

- 时间 O(n)：遍历一次。
- 空间 O(1)：只有一个累加变量。

## 易错点

- 累加器初值必须是 0，不能用 `nums[0]` 又从下标 0 开始循环（那会把第一个数抵消掉）。
- 这个技巧只适用于"其余元素出现**偶数**次"。如果其余出现三次（LeetCode 137），异或不再适用，要改成按位统计 1 的个数再对 3 取模。
- 如果有**两个**只出现一次的数（LeetCode 260），整体异或得到 `a^b`，还要用它的某一位 1 把数组分成两组再各自异或。
- 不要用求和相减（`2*sum(set) - sum(nums)`）替代，既要额外空间又可能溢出。
