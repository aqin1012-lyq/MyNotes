## 题意

给一个 `m x n` 的网格，每个格子里是一个非负整数。从左上角走到右下角，每一步只能**向右**或**向下**，求路径上所有数字之和的最小值（起点和终点的数都算）。

```
输入：grid = [[2,3,1],[4,1,5],[1,6,2]]
输出：13
解释：2 → 3 → 1 → 5 → 2，和为 13（沿第一行走到头再向下也是 13）
```

```
输入：grid = [[1,2],[1,1]]
输出：3
解释：1 → 1 → 1，先向下再向右
```

## 思路

暴力做法是枚举所有从左上到右下的路线，路线数是组合数级别（见 [[algo:unique-paths]]），指数爆炸。但仔细看：走到 `(i,j)` 的最小代价，只取决于"走到上面格子的最小代价"和"走到左边格子的最小代价"，与更早怎么走无关，这就是**最优子结构**，可以用 DP。

- **dp 定义**：`dp[i][j]` = 从 `(0,0)` 走到 `(i,j)`（含两端）的最小路径和。
- **转移**：`dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]`。
- **初始化**：`dp[0][0] = grid[0][0]`；第 0 行只能从左来，`dp[0][j] = dp[0][j-1] + grid[0][j]`；第 0 列只能从上来，`dp[i][0] = dp[i-1][0] + grid[i][0]`。
- **遍历顺序**：行从上到下，每行从左到右。

:::tip 关键点
为什么贪心不行？每步只看右和下哪个小，可能被一个小数引进"死胡同"，后面全是大数。DP 的正确性来自：任何到 `(i,j)` 的路线最后一步必然来自上或左，取两者最优再加当前格，就覆盖了所有可能。首行首列只有一个来源，要单独初始化，不能当成 min(0, ...)。
:::

用例子 `grid = [[2,3,1],[4,1,5],[1,6,2]]` 推演 dp 表：

```
grid            dp
2  3  1         2   5   6
4  1  5         6   6  11
1  6  2         7  12  13
```

- `dp[1][1] = min(5, 6) + 1 = 6`
- `dp[1][2] = min(6, 6) + 5 = 11`
- `dp[2][1] = min(6, 7) + 6 = 12`
- `dp[2][2] = min(11, 12) + 2 = 13`

## Java 题解

```java
import java.util.*;

class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        // 一维滚动：dp[j] 表示走到当前行第 j 列的最小路径和
        int[] dp = new int[n];
        dp[0] = grid[0][0];
        // 第 0 行只能从左边来
        for (int j = 1; j < n; j++) {
            dp[j] = dp[j - 1] + grid[0][j];
        }
        for (int i = 1; i < m; i++) {
            // 第 0 列只能从上面来
            dp[0] += grid[i][0];
            for (int j = 1; j < n; j++) {
                // dp[j] 此时是上方，dp[j-1] 是左方
                dp[j] = Math.min(dp[j], dp[j - 1]) + grid[i][j];
            }
        }
        return dp[n - 1];
    }
}
```

## 复杂度

- 时间 O(m·n)：每个格子计算一次。
- 空间 O(n)：只保留一行 dp；若允许修改入参，也可以直接在 `grid` 上原地累加做到 O(1) 额外空间。

## 易错点

- 首行首列不能套通用转移：如果用 `min(上, 左)` 且越界位置当 0，会让首行错误地"从上方免费进入"。要么单独初始化，要么把越界位置当成 `Integer.MAX_VALUE`。
- 用 `Integer.MAX_VALUE` 当哨兵时别直接加 `grid[i][j]`，会溢出成负数；先取 min 再加，且保证至少有一个方向合法。
- 起点的值也要算进去，`dp[0][0] = grid[0][0]` 而不是 0。
- 在面试中原地修改 `grid` 前最好问一句能不能改入参。
