## 题意

数组 `prices[i]` 是某只股票第 i 天的价格。你最多只能做**一次**交易：某一天买入，之后的某一天卖出（不能先卖后买）。返回能获得的最大利润；无论怎么做都赚不到钱时返回 0。

```
输入：prices = [8,3,6,2,7,4]
输出：5
解释：第 3 天（价格 2）买入，第 4 天（价格 7）卖出，利润 5
```

```
输入：prices = [9,7,4,1]
输出：0
解释：价格一路下跌，不交易
```

## 思路

暴力做法：枚举所有买入日 i 和卖出日 j > i，取 `prices[j] - prices[i]` 的最大值，O(n²)。

瓶颈在于：对每个卖出日 j，我们都在重新扫描前面所有天找最低价。其实"前面的最低价"可以边走边维护——走到第 j 天时，`minPrice` 就是 `prices[0..j-1]` 的最小值，今天卖出的最佳利润就是 `prices[j] - minPrice`。一次遍历即可。

:::tip 关键点
固定卖出日，最优买入日一定是它之前的最低价那天。一边遍历一边维护历史最低价，用"今天价格 - 历史最低"更新答案。
:::

`prices = [8,3,6,2,7,4]` 推演：

```
day price minPrice(含当天) 今天卖出利润 best
0   8     8                 0            0
1   3     3                 0            0
2   6     3                 3            3
3   2     2                 0            3
4   7     2                 5            5
5   4     2                 2            5
```

注意第 3 天出现了更低价 2，即使前面已有利润 3，后面用 2 买入仍然可能更好，所以最低价要持续更新。

## Java 题解

```java
import java.util.*;

class Solution {
    public int maxProfit(int[] prices) {
        int minPrice = Integer.MAX_VALUE; // 到目前为止的最低买入价
        int best = 0;                     // 不交易时利润为 0
        for (int p : prices) {
            // 先更新最低价（当天买当天卖利润为 0，不影响结果）
            minPrice = Math.min(minPrice, p);
            // 假设今天卖出
            best = Math.max(best, p - minPrice);
        }
        return best;
    }
}
```

## 复杂度

- 时间 O(n)：只遍历一次。
- 空间 O(1)：两个变量。

## 易错点

- 直接用"全局最大值 - 全局最小值"是错的：最大值可能出现在最小值之前，比如 `[7,1,...]` 里 7 在 1 前面不能卖。
- `best` 初始化为 0 而不是负数，题目要求亏钱时返回 0（不交易）。
- 先更新最低价再算利润也没问题，因为当天买当天卖利润为 0；但如果先算利润，`minPrice` 初值 `MAX_VALUE` 会让 `p - minPrice` 变成很大的负数，同样不影响，只是要清楚为什么对。
