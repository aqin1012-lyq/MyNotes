## 题意

给一个只包含 `'('` 和 `')'` 的字符串 `s`，找出其中最长的**有效括号子串**（必须连续，且括号完全配对、嵌套正确）的长度。字符串可能为空。

```
输入：s = ")()(())"
输出：6
解释：最长有效子串是 "()(())"
```

```
输入：s = "))(("
输出：0
```

## 思路

暴力：枚举所有偶数长度的子串，用计数器检查是否有效，O(n³)，优化检查后也要 O(n²)。瓶颈在于没有利用"有效串可以拼接、可以嵌套"这一结构。

有效括号串一定以 `')'` 结尾，所以只在 `')'` 处计算：

- **dp 定义**：`dp[i]` = 以 `s[i]` **结尾**的最长有效子串长度；`s[i] == '('` 时为 0。
- **转移**（`s[i] == ')'`）：
- 情况一，`s[i-1] == '('`，形如 `...()`：`dp[i] = dp[i-2] + 2`，把前面紧挨着的有效串接上。
- 情况二，`s[i-1] == ')'`，形如 `...))`：先跳过以 `i-1` 结尾的那段有效串，看它前面的位置 `j = i - dp[i-1] - 1`；若 `s[j] == '('`，则 `dp[i] = dp[i-1] + 2 + dp[j-1]`（外层包一对，再接上 `j` 之前紧挨着的有效串）。
- **初始化**：全部为 0；下标 `i-2`、`j-1` 小于 0 时按 0 处理。
- **遍历顺序**：`i` 从 1 到 `n-1` 从左往右，答案是所有 `dp[i]` 的最大值。

:::tip 关键点
情况二里最容易漏掉的是末尾的 `+ dp[j-1]`：内层包好之后，左边可能还紧贴着另一段有效串，比如 `()(())` 里最后一个 `)` 需要把开头的 `()` 也接上。
:::

用 `s = ")()(())"` 填表：

```
i     0  1  2  3  4  5  6
s[i]  )  (  )  (  (  )  )
dp    0  0  2  0  0  2  6
```

- `dp[2]`：情况一，`dp[0] + 2 = 2`
- `dp[5]`：情况一，`dp[3] + 2 = 2`
- `dp[6]`：情况二，`j = 6 - 2 - 1 = 3`，`s[3] = '('`，`dp[6] = 2 + 2 + dp[2] = 6`

`dp[i]` 可能依赖很远的 `dp[j-1]`，无法滚动压缩；想要 O(1) 空间可以用"其他解法"中提到的左右两遍计数。

## Java 题解

```java
import java.util.*;

class Solution {
    public int longestValidParentheses(String s) {
        int n = s.length(), best = 0;
        int[] dp = new int[n];
        for (int i = 1; i < n; i++) {
            if (s.charAt(i) == '(') continue; // 以 '(' 结尾不可能有效
            if (s.charAt(i - 1) == '(') {
                // 情况一：...()
                dp[i] = (i >= 2 ? dp[i - 2] : 0) + 2;
            } else {
                // 情况二：...))，跳过以 i-1 结尾的有效段
                int j = i - dp[i - 1] - 1;
                if (j >= 0 && s.charAt(j) == '(') {
                    // 外层包一对，再接上 j 左边紧挨着的有效段
                    dp[i] = dp[i - 1] + 2 + (j >= 1 ? dp[j - 1] : 0);
                }
            }
            best = Math.max(best, dp[i]);
        }
        return best;
    }
}
```

## 复杂度

- 时间 O(n)：每个位置 O(1) 计算。
- 空间 O(n)：dp 数组；左右两遍计数法可以做到 O(1)。

## 易错点

- 情况二漏掉 `+ dp[j-1]`，`"()(())"` 会算成 4 而不是 6。
- `j` 可能小于 0（比如 `"())"` 中最后一个 `)`），要先判断 `j >= 0` 再取 `s.charAt(j)`。
- `i - 2`、`j - 1` 越界时按 0 处理。
- 答案是所有 `dp[i]` 的最大值，不是 `dp[n-1]`。
- 只用一个计数器从左往右扫会漏掉 `"(()"` 这类左括号多余的情况，需要再从右往左扫一遍。

## 其他解法

栈：栈里存下标，栈底始终放"最后一个没有被匹配的 `)` 的位置"作为分界（初始放 -1）。遇到 `(` 压入下标；遇到 `)` 先弹出，若栈空说明当前 `)` 无法匹配，把它的下标压入作为新分界，否则 `i - 栈顶` 就是以 `i` 结尾的有效长度。

```java
import java.util.*;

class Solution {
    public int longestValidParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1); // 分界：最后一个未匹配 ')' 的位置
        int best = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {
                stack.pop();
                if (stack.isEmpty()) {
                    stack.push(i); // 当前 ')' 无法匹配，成为新分界
                } else {
                    best = Math.max(best, i - stack.peek());
                }
            }
        }
        return best;
    }
}
```

另有 O(1) 空间的做法：用 `left`、`right` 两个计数器从左往右扫，相等时更新答案，`right > left` 时清零；再从右往左对称扫一遍。

## 一句话记忆

`dp[i]` 为以 `)` 结尾的最长有效长度：`()` 接 `dp[i-2]`，`))` 就跳过内层找匹配的 `(`，别忘了再接上 `dp[j-1]`。
