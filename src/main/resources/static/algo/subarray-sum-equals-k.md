## 题意

给一个整数数组 `nums`（可能有负数和 0）和一个整数 `k`，统计有多少个**连续非空**子数组的元素和恰好等于 `k`。只要起止下标不同就算不同的子数组。

```
输入：nums = [2,-1,1,2], k = 2
输出：4
解释：[2]、[2,-1,1]、[-1,1,2]、[2](最后一个) 都等于 2
```

```
输入：nums = [0,0], k = 0
输出：3
解释：[0]、[0]、[0,0]
```

## 思路

暴力：枚举起点 i，再从 i 往右累加到 j，每次判断和是否为 k，O(n²)。

能不能用滑动窗口？不能——数组里有负数，窗口扩大时和不一定变大，缩小时也不一定变小，失去了单调性。

换成**前缀和**：设 `pre[j]` 是前 j 个元素之和，那么子数组 `(i, j]` 的和 = `pre[j] - pre[i]`。要它等于 k，就是 `pre[i] = pre[j] - k`。于是问题变成：走到 j 时，前面出现过多少个前缀和恰好等于 `pre[j] - k`？这和两数之和一模一样，用 HashMap 记"前缀和 → 出现次数"。

:::tip 关键点
区间和 = 两个前缀和之差。"数有多少个区间和为 k"就变成"边走边查前面有多少个前缀和等于 `当前前缀和 - k`"。map 要预先放入 `{0: 1}`，代表空前缀，否则从下标 0 开始的子数组会被漏掉。
:::

推演 `[2,-1,1,2], k = 2`：

```
j  num  pre  pre-k  count[pre-k]  ans  map(after)
-  -    0    -      -             0    {0:1}
0  2    2    0      1             1    {0:1,2:1}
1  -1   1    -1     0             1    {0:1,2:1,1:1}
2  1    2    0      1             2    {0:1,2:2,1:1}
3  2    4    2      2             4    {0:1,2:2,1:1,4:1}
```

## Java 题解

```java
import java.util.*;

class Solution {
    public int subarraySum(int[] nums, int k) {
        // 前缀和 -> 出现次数
        Map<Integer, Integer> count = new HashMap<>();
        count.put(0, 1); // 空前缀，处理从下标 0 开始的子数组
        int pre = 0, ans = 0;
        for (int x : nums) {
            pre += x;
            // 前面有多少个前缀和等于 pre - k，就有多少个以当前位置结尾的子数组和为 k
            ans += count.getOrDefault(pre - k, 0);
            // 先查后放，避免把当前前缀自己算进去（k = 0 时尤其重要）
            count.merge(pre, 1, Integer::sum);
        }
        return ans;
    }
}
```

## 复杂度

- 时间 O(n)：一次遍历，每步 HashMap 操作均摊 O(1)。
- 空间 O(n)：最多存 n+1 个不同的前缀和。

## 易错点

- 忘了 `count.put(0, 1)`，会漏掉所有从下标 0 开始的子数组。
- 先放后查：k = 0 时会把"空子数组"算进去，答案偏大。
- 有负数时不能用滑动窗口，这是这题的核心陷阱。
- map 存的是**次数**而不是下标，因为同一个前缀和可能出现多次（如例子中 pre=2 出现了两次）。
