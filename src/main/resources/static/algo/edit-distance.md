## 题意

给两个单词 `word1` 和 `word2`，每次操作可以对 `word1` **插入**一个字符、**删除**一个字符或**替换**一个字符，求把 `word1` 变成 `word2` 所需的最少操作次数。两个串长度都在 500 以内，可以为空，只含小写字母。

```
输入：word1 = "sun", word2 = "snow"
输出：3
解释：删掉 u 得到 "sn"，再插入 o、插入 w 得到 "snow"
```

```
输入：word1 = "", word2 = "ab"
输出：2
解释：空串只能插入两次
```

## 思路

暴力做法是递归：比较两个串的当前字符，不相等就三种操作各试一次，分支因子为 3，指数级。但递归的状态只有"`word1` 处理到第几个、`word2` 处理到第几个"两个维度，一共 (m+1)(n+1) 种，大量重复，所以用 DP。

同样只看两个前缀的**最后一个字符**：

- **dp 定义**：`dp[i][j]` = 把 `word1` 的前 `i` 个字符变成 `word2` 的前 `j` 个字符的最少操作数。
- **转移**：若 `word1[i-1] == word2[j-1]`，末尾不用动，`dp[i][j] = dp[i-1][j-1]`；否则 `dp[i][j] = 1 + min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1])`，三项分别对应：
- 替换：把 `word1[i-1]` 改成 `word2[j-1]`，之后两边都去掉末尾，来自左上。
- 删除：删掉 `word1[i-1]`，剩下 `word1` 前 `i-1` 个去匹配 `word2` 前 `j` 个，来自上方。
- 插入：在 `word1` 末尾插入 `word2[j-1]`，与之抵消，剩下 `word1` 前 `i` 个去匹配 `word2` 前 `j-1` 个，来自左方。
- **初始化**：`dp[i][0] = i`（删光），`dp[0][j] = j`（全插入）。
- **遍历顺序**：`i` 从 1 到 m，`j` 从 1 到 n，依赖上、左、左上。

:::tip 关键点
三种操作 ↔ 三个方向：左上 = 替换（或相等时免费），上 = 删 `word1`，左 = 插入。为什么只看末尾就够？在任意一个最优方案里，看 `word2` 的最后一个字符是怎么来的：它由 `word1` 的末尾字符变来（原本相等或被替换）→ 左上；它是新插入的 → 左；它由 `word1` 更靠前的某个字符变来，那么 `word1` 的末尾字符后面已经没有位置可对应（操作不改变相对顺序），只能被删掉 → 上。三种情况必居其一，所以取三者最小不会漏掉最优解。初始化那一行一列千万不能写成 0。
:::

用 `word1 = "sun"`（行）、`word2 = "snow"`（列）推演：

```
         ""  s   n   o   w
    ""    0  1   2   3   4
    s     1  0   1   2   3
    u     2  1   1   2   3
    n     3  2   1   2   3
```

- `dp[1][1]`：`s == s`，取左上 0。
- `dp[2][2]`（"su" → "sn"）：`u != n`，`1 + min(0, 1, 1) = 1`，即替换 u 为 n。
- `dp[3][2]`（"sun" → "sn"）：`n == n`，取左上 `dp[2][1] = 1`（删掉 u）。
- `dp[3][4]`：`n != w`，`1 + min(2, 3, 2) = 3`。

## Java 题解

```java
import java.util.*;

class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length(), n = word2.length();
        // dp[i][j]：word1 前 i 个字符变成 word2 前 j 个字符的最少操作数
        int[][] dp = new int[m + 1][n + 1];
        // 变成空串：删 i 次
        for (int i = 0; i <= m; i++) dp[i][0] = i;
        // 从空串变过来：插入 j 次
        for (int j = 0; j <= n; j++) dp[0][j] = j;
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    // 末尾相同，不花操作
                    dp[i][j] = dp[i - 1][j - 1];
                } else {
                    int replace = dp[i - 1][j - 1]; // 替换
                    int delete = dp[i - 1][j];      // 删除 word1 末尾
                    int insert = dp[i][j - 1];      // 在 word1 末尾插入
                    dp[i][j] = 1 + Math.min(replace, Math.min(delete, insert));
                }
            }
        }
        return dp[m][n];
    }
}
```

## 复杂度

- 时间 O(m·n)：填满 (m+1)(n+1) 的表，每格 O(1)。
- 空间 O(m·n)：可以像 LCS 一样用一维数组 + 一个变量保存左上角，压到 O(n)。

## 易错点

- 第 0 行 / 第 0 列要初始化为 `j` / `i`，不是 0：把 "abc" 变成空串要删 3 次。
- 三个方向对应的操作容易记反：上方 `dp[i-1][j]` 是**删除** `word1` 的字符，左方 `dp[i][j-1]` 是**插入**。记反不影响答案数值，但面试官追问时要能讲清。
- 字符相等时直接取左上，不要再 `+1`，也不必再和上、左比较（相等时取左上一定不劣）。
- 任一串为空时循环不执行，直接返回另一个串的长度，初始化已经覆盖。

## 举一反三

- [[algo:longest-common-subsequence]]：同样的"两串前缀"二维表；如果只允许插入和删除，编辑距离 = `m + n - 2 * LCS`。
- [[algo:minimum-path-sum]]：同样是在网格上取 min，编辑距离可以看成在 (m+1)x(n+1) 网格上找最短路径，只是斜着走在字符相等时免费。
- 工程联系：搜索框的拼写纠错 / "你是不是要找"、模糊匹配用户名、日志聚类里相似字符串判断，常用的就是 Levenshtein 距离，也就是这题。

## 一句话记忆

末尾相等取左上；不等则 1 + min(左上替换, 上删除, 左插入)，首行首列初始化为 j 和 i。
