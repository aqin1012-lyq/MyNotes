## 题意

有一个 `m` 行 `n` 列的网格，机器人从左上角出发，每一步只能**向右**或**向下**走一格，问走到右下角一共有多少条不同的路线。`1 <= m, n <= 100`，题目保证答案在 int 范围内。

```
输入：m = 3, n = 4
输出：10
解释：总共要向下 2 步、向右 3 步，不同的排列顺序有 10 种
```

```
输入：m = 1, n = 5
输出：1
解释：只有一行，只能一路向右
```

## 思路

暴力做法是 DFS：从起点出发，每一步分"向右 / 向下"两支递归，走到终点计数 +1。路径长度是 `m+n-2`，分支数是指数级的。瓶颈在于大量**重复子问题**：从格子 `(i,j)` 到终点的路线数，不管你是从哪条路走到 `(i,j)` 的，答案都一样，却被反复计算。

反过来想"到达 `(i,j)` 有多少种走法"：最后一步要么从上面 `(i-1,j)` 下来，要么从左边 `(i,j-1)` 过来，两类路线互不重叠，所以直接相加。

- **dp 定义**：`dp[i][j]` = 从 `(0,0)` 走到 `(i,j)` 的不同路线数。
- **转移**：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`。
- **初始化**：第 0 行和第 0 列全是 1（只能一路向右 / 一路向下）。
- **遍历顺序**：行从上到下、每行从左到右，保证算 `(i,j)` 时上方和左方都已算好。

:::tip 关键点
"只能向右/向下"意味着每个格子只依赖上和左，这是一张**无环**的依赖图，按行扫描就是天然的拓扑序。又因为只依赖上一行和本行左边，二维表可以压成一维：`dp[j] += dp[j-1]`，右边的 `dp[j]` 在加之前还是"上一行"的值。
:::

用 `m = 3, n = 4` 推演 dp 表：

```
        j=0  j=1  j=2  j=3
i=0      1    1    1    1
i=1      1    2    3    4
i=2      1    3    6   10
```

例如 `dp[2][2] = dp[1][2] + dp[2][1] = 3 + 3 = 6`，右下角 `dp[2][3] = 4 + 6 = 10`。

## Java 题解

```java
import java.util.*;

class Solution {
    public int uniquePaths(int m, int n) {
        // 一维滚动数组：dp[j] 表示当前行走到第 j 列的路线数
        int[] dp = new int[n];
        // 第 0 行全是 1
        Arrays.fill(dp, 1);
        for (int i = 1; i < m; i++) {
            // dp[0] 始终是 1（第 0 列只能一路向下）
            for (int j = 1; j < n; j++) {
                // 加之前 dp[j] 是上一行的值（上方），dp[j-1] 是本行已更新的值（左方）
                dp[j] += dp[j - 1];
            }
        }
        return dp[n - 1];
    }
}
```

## 复杂度

- 时间 O(m·n)：每个格子算一次，每次 O(1)。
- 空间 O(n)：只保留一行；如果用二维表则是 O(m·n)。

## 易错点

- 第 0 行、第 0 列必须初始化为 1，而不是 0；忘了初始化会导致全表都是 0。
- 一维压缩时内层 `j` 必须**从左往右**，因为要用的是本行已经更新过的 `dp[j-1]`；这和 0-1 背包的倒序正好相反，别混。
- `m = 1` 或 `n = 1` 时外层 / 内层循环不执行，直接返回 1，要确认代码能自然覆盖。
- 组合数写法中间结果会超过 int，要用 long，且要边乘边除保证每步都是整数。

## 其他解法

总共要走 `m-1` 步向下、`n-1` 步向右，路线就是在 `m+n-2` 步里挑出哪几步向下，答案是组合数 `C(m+n-2, m-1)`。按 `C(k, r) = C(k, r-1) * (k-r+1) / r` 递推，每一步结果都恰好是某个组合数，所以整除不会出错。

```java
import java.util.*;

class Solution {
    public int uniquePaths(int m, int n) {
        // C(m+n-2, m-1)：从 m+n-2 步里选 m-1 步向下
        long ans = 1;
        int total = m + n - 2;
        int r = m - 1;
        for (int i = 1; i <= r; i++) {
            // 先乘后除，每一步 ans 都是 C(total-r+i, i)，一定能整除
            ans = ans * (total - r + i) / i;
        }
        return (int) ans;
    }
}
```
