## 题意

给一个非负整数数组 `nums`，从下标 0 出发，在位置 i 最多能向后跳 `nums[i]` 步。题目保证一定能到达最后一个下标，求**最少**跳几次。

```
输入：nums = [2,4,1,1,3,1]
输出：2
解释：0 → 1（跳 1 步）→ 5（跳 4 步）
```

```
输入：nums = [5]
输出：0
解释：起点就是终点，不用跳
```

## 思路

暴力 DP：`dp[i]` 表示到达 i 的最少步数，对每个 i 更新它能跳到的所有位置，O(n²)。

更好的视角是把它看成 **BFS 分层**：第 0 层是起点 0；第 1 层是从第 0 层一步能到的所有位置；第 2 层是从第 1 层一步能到的新位置……终点第一次出现在第几层，答案就是几。又因为可达位置是连续的（见 [[algo:jump-game]]），每一层都是一个连续区间，不需要真的用队列，只要两个变量：

- `end`：当前这一层的右边界。
- `far`：遍历当前层时，下一层能到的最远位置。

从左到右扫描，每个位置都用 `i + nums[i]` 更新 `far`；当 `i` 走到 `end` 时，说明当前层扫完了，必须再跳一次，`steps++` 并把 `end` 设为 `far`。

:::tip 关键点
隐式 BFS：`[上一层end+1, end]` 是一层，扫这一层时记录下一层最远能到 `far`；走到 `end` 就跳一次、进入下一层。循环只到 `n - 2`，避免站在终点时多算一跳。
:::

`nums = [2,4,1,1,3,1]` 推演：

```
i nums[i] far  i==end?       steps end
0 2       2    是 (end=0)    1     2
1 4       5    否            1     2
2 1       5    是 (end=2)    2     5
end=5 已覆盖终点，提前结束，答案 2
```

## Java 题解

```java
import java.util.*;

class Solution {
    public int jump(int[] nums) {
        int steps = 0;
        int end = 0; // 当前这一跳能覆盖的右边界
        int far = 0; // 在当前范围内再跳一次能到的最远位置
        // 不遍历最后一个位置：到达终点后不需要再跳
        for (int i = 0; i < nums.length - 1; i++) {
            far = Math.max(far, i + nums[i]);
            if (i == end) {  // 当前层走完，必须再跳一次
                steps++;
                end = far;
                if (end >= nums.length - 1) break; // 已经能覆盖终点，提前结束
            }
        }
        return steps;
    }
}
```

## 复杂度

- 时间 O(n)：每个位置只看一次。
- 空间 O(1)。

## 易错点

- 循环写到 `i < n` 会在 `i == n-1 == end` 时多加一步，例如 `[5]` 会返回 1。
- `steps++` 的时机是"走到当前层边界"，而不是每次 `far` 变大就加一。
- 贪心的不是"每次跳最远"（从 0 跳 2 步到下标 2 再跳，只能到 3），而是"在当前能到的范围里，挑一个能让下一跳最远的位置"。
- 本题保证可达；如果不保证，要在 `i > end` 时返回 -1。

## 其他解法

DP 写法便于理解但 O(n²)：`dp[0] = 0`，对每个 i，把 `dp[i+1..i+nums[i]]` 更新为 `min(dp[j], dp[i] + 1)`。面试时可以先说它，再优化成上面的分层贪心。

## 举一反三

- [[algo:jump-game]]：只问能不能到，维护一个 `reach` 就够了。
- [[algo:rotting-oranges]]：显式 BFS 按层数"分钟数"，本题是它在一维上的隐式版本。
- [[algo:coin-change]]：同样是"最少步数"，但每步选择不连续，只能 DP 或 BFS。
