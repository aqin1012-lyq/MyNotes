## 题意

把整数数组看成一个排列，按字典序把它**原地**改成"下一个更大的排列"，即所有由这些数组成的排列中，比当前大的里面最小的那个。如果当前已经是最大排列（整体降序），就改成最小排列（整体升序）。只能用常数额外空间，数组中可能有重复元素。

```
输入：nums = [1,3,5,4,2]
输出：[1,4,2,3,5]
```

```
输入：nums = [3,2,1]
输出：[1,2,3]
解释：已经是最大排列，回到最小
```

## 思路

暴力做法是生成全部排列、排序、找到当前的下一个，O(n!)，完全不可行。要直接构造，先想清楚"下一个"意味着什么：变大，但变大的幅度尽可能小。

类比数字 `13542` 的下一个更大的数：要让变化尽量发生在**低位**（右边）。三步：

1. **找拐点**：从右往左找第一个 `nums[i] < nums[i+1]` 的位置 `i`。`i` 右边整段是非递增的。
2. **找替换者**：再从右往左找第一个 `nums[j] > nums[i]` 的 `j`，交换 `nums[i]` 和 `nums[j]`。
3. **翻转后缀**：把 `i+1` 到末尾整段反转，变成升序。

如果第 1 步找不到 `i`（整体非递增），直接把整个数组反转。

:::tip 为什么对
第 1 步：`i` 右边是非递增的，说明这段已经是这些数能排出的**最大**样子，只动这段不可能再变大，所以必须动 `i`；而 `i` 又是能变大的最右位置，改它带来的增量最小。第 2 步：`i` 位置要换成后缀里"比它大的数中最小的那个"才能增量最小；后缀是降序的，从右往左第一个大于 `nums[i]` 的就是它。第 3 步：交换后后缀仍然非递增（`nums[j]` 左边的都 ≥ 它 > 旧的 `nums[i]`，右边的都 ≤ 旧的 `nums[i]`），而 `i` 已经变大了，后缀应该取**最小**的排法即升序，降序段反转就是升序，O(n) 而不必排序。
:::

用 `nums = [1,3,5,4,2]` 推演：

```
step                   nums          说明
init                   [1,3,5,4,2]
find i (3 < 5)         [1,3,5,4,2]   i = 1，后缀 [5,4,2] 降序
find j (4 > 3)         [1,3,5,4,2]   j = 3，2 不大于 3，4 是第一个
swap(i, j)             [1,4,5,3,2]   后缀 [5,3,2] 仍降序
reverse(i+1..end)      [1,4,2,3,5]   后缀变升序
```

## Java 题解

```java
import java.util.*;

class Solution {
    public void nextPermutation(int[] nums) {
        int n = nums.length;
        // 1. 从右往左找第一个"下降"的位置 i：nums[i] < nums[i+1]
        int i = n - 2;
        while (i >= 0 && nums[i] >= nums[i + 1]) i--;
        if (i >= 0) {
            // 2. 后缀是非递增的，从右往左第一个比 nums[i] 大的就是"刚好大一点"的数
            int j = n - 1;
            while (nums[j] <= nums[i]) j--;
            swap(nums, i, j);
        }
        // 3. 后缀仍是非递增的，反转成升序即最小排法；i = -1 时就是整体反转
        reverse(nums, i + 1, n - 1);
    }

    private void swap(int[] nums, int a, int b) {
        int t = nums[a];
        nums[a] = nums[b];
        nums[b] = t;
    }

    private void reverse(int[] nums, int l, int r) {
        while (l < r) swap(nums, l++, r--);
    }
}
```

## 复杂度

- 时间 O(n)：找 `i`、找 `j`、反转各最多扫一遍。
- 空间 O(1)：原地交换和反转。

## 易错点

- 两处比较都要处理**相等**：找 `i` 用 `nums[i] >= nums[i+1]` 继续左移，找 `j` 用 `nums[j] <= nums[i]` 继续左移。写成严格不等号在有重复元素时（如 `[1,5,1]`）会找错位置。
- 第 3 步是**反转**，不是排序；用排序也对但变成 O(n log n)，而且说明没想清楚后缀的单调性。
- 反转的起点是 `i + 1`，不是 `i`，也不是 `j`。
- 找不到 `i` 时（`i = -1`）要反转整个数组，上面代码让 `reverse(nums, 0, n-1)` 自然覆盖了这种情况。
- 找 `j` 的循环不需要判断越界：既然 `nums[i] < nums[i+1]`，最迟在 `i+1` 处一定停下。
